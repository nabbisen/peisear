## §3 — the changelog

**This release's subject is the front door**: the path in, the pictures, the
name, and a scan so the next drift is caught by a test rather than by a
reader. Five beats.

1. **Lead with the name, because it is the only thing a running instance
   shows differently.** The interface used to call itself **"Issue Tracker"**
   — in the navbar of every page and in seven page titles — so the product
   never said its own name. It now reads **`peisear`**. Say that the crates.io
   and docs.rs one-line descriptions changed with it, and that
   **`README.md`'s own repositioning is deliberately not in this release**
   (`RFC 0016` proposal 2, `0.50.0`). A reader who sees the name change and
   then reads an unchanged README should find that difference explained, not
   discover it.
2. **The start path could not be followed, and now can.** The Quick Start's
   first command opened **a tarball no release provides** (0 assets,
   measured); `installation.md` named **rustc 1.85**, which cannot build the
   workspace; it claimed the stylesheets load **from a CDN** when they are
   vendored; and the crates.io page's **ten relative links all 404'd**
   because `readme` points outside the crate. **Four wrong instructions in
   the three documents a newcomer reads first.**
3. **The product has pictures of itself, for the first time.** Three
   screenshots — board, list, issue detail — in `README.md` and the
   first-run walkthrough. **Generated by the same harness that drives the
   browser gates**, not hand-captured, and regenerated and looked at during
   the release sweep's fifth pass, so a stale image is a thing someone
   notices rather than a thing nobody owns.
4. **A scan for the half of documentation drift a scan can catch.** Six rules
   comparing a document against its source of truth: the crate set against
   `crates/`, the MSRV against `Cargo.toml`, the deployment manifest against
   `static/`, documented defaults against `config.rs`, committed citations to
   gitignored paths, and `README.md`'s absolute image URLs against the
   filesystem. **Say what it cannot do**: no rule judges prose, because none
   can — that is why the sweep's reading pass exists beside it.
5. **What this release does not fix.** The deployment manifest still lists
   two of eight shipped files, both architecture documents still omit
   `peisear-i18n`, and ~130 committed citations still point at a gitignored
   directory — `DOCS-006`, `0.50.0`. **Name them.** A release whose subject is
   documentation accuracy should not leave the reader to discover its own
   remaining gaps.

**Two things the notes must not claim.** That the README now describes the
product correctly — it does not, by design, and beat 1 says so. And that the
documentation scan covers documentation drift generally — it covers the
countable half, and beat 4 says which.
