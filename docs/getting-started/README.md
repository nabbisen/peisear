# Getting Started

A download, a `docker run`, or `cargo install` — whichever you pick,
the same board is one command away.

1. [Install](install.md) — a prebuilt binary, a container image, or
   `cargo install` if you already have Rust; each ends at the same URL
2. [Configure](configuration.md) — environment variables and the `.env`
   file, only if the defaults aren't what you want
3. [First run](first-run.md) — register, create your first issue, the
   full walkthrough

Reading or changing the code instead of just running it? Start at
[Build from source](build-from-source.md).

If you want to skim the architecture before running anything, head to
[../architecture/overview.md](../architecture/overview.md) first.
